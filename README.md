# 🎬 Netflix Data Analysis & Exploratory Data Analysis

A complete Exploratory Data Analysis (EDA) project performed on the Netflix Movies & TV Shows dataset using Python.

## 📌 Project Overview

This project analyzes **8,807 Netflix titles** across multiple attributes to discover trends in genres, countries, ratings, release years, and content growth.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Project Objectives

* Clean and preprocess Netflix dataset.
* Analyze Movies vs TV Shows.
* Discover Top Countries producing Netflix content.
* Analyze Genre Distribution.
* Analyze Ratings and Audience Categories.
* Study Content Growth Over Time.

## 📈 Visualizations

* Movie vs TV Show Distribution
* Top 10 Genres
* Top 10 Countries
* Content Added Every Year
* Correlation Heatmap
* Duration Distribution

## 📁 Dataset

Netflix Movies & TV Shows Dataset from Kaggle.

## 🚀 Results

* Movies dominate Netflix catalog.
* United States contributes the highest number of titles.
* Drama and International Movies are among the most common genres.
* Netflix content grew rapidly after 2016.
